# Future

以下均为后续方向，不是当前已提供的功能：

1. 完善 CLI 后续版本与发布流程；`qwen-latex-cli@0.1.0` 已提交 npm 发布。
2. 在本次 BF16 / Q4_K_M GGUF 发布完成后，验证 Ollama 端到端使用并测量量化与原始 adapter 的准确率差异。
3. 提供可选托管推理服务；保留用户自行使用 Ollama 的路径，不绑定服务账号。
4. 在独立协议下比较采样、重复控制和有限输出预算，区分基座与 SFT 的长输出稳定性。当前结果不足以确诊过拟合。
5. 扩展独立公式组与中文真实输入评测。最终 test 不用于调参，任何新增数据继续遵守盲审和结构/近亲隔离。

BF16 / GGUF 转换已按追加要求完成，HF 替换上传正在进行；上述训练、评测和部署留待后续，不重建桌面/TUI。
