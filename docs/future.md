# Future

以下均为后续方向，不是当前已提供的功能：

1. 确定 npm 发布账号、包名与发布流程，再发布当前轻量 CLI。
2. 为已选 v5.2 adapter 制作并验证 Ollama 可用发布物，记录转换/量化与 HF adapter 的差异；当前只发布了 adapter 归档。
3. 提供可选托管推理服务；保留用户自行使用 Ollama 的路径，不绑定服务账号。
4. 在独立协议下比较采样、重复控制和有限输出预算，区分基座与 SFT 的长输出稳定性。当前结果不足以确诊过拟合。
5. 扩展独立公式组与中文真实输入评测。最终 test 不用于调参，任何新增数据继续遵守盲审和结构/近亲隔离。

本轮不启动上述训练、推理、模型转换或部署，也不重建桌面/TUI。
