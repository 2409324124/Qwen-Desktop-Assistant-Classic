MATH-500 主指标保持运行前冻结的规则。检查基座输出后发现，这个保守规则会同时拒绝无害的尾随勾号、单位和解释。于是仅追加“最后一个 boxed 匹配”诊断，两模型使用同一算法，不重跑生成、不修改标签或主分数。该辅助诊断不检查尾随内容是否矛盾，不能把所有匹配一律升级为已验证正确。主指标的提升中有格式/可验证性变化，不能全归因于数学推理提升。

AIME25 未采用上述保守最终 boxed 规则；其官方抽取允许使用较早出现的 boxed 答案，所以即使输出达到预算也可能得分。21/30 与 22/30 达到预算，说明本轮主要衡量 4096-token 限制下的表现，不能代表充分推理预算下的能力。原始 `looks_truncated` 启发式计数保留在 `comparison.json`，存在 Markdown 误报，不用作主要截断统计。
